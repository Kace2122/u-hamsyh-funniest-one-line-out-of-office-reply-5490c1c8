Entry (164 characters, one line):

> I'm out of the office — my inbox is now managed by my houseplant, which has read your email, felt absolutely nothing, and will reply at the speed of photosynthesis.

## Run it

```sh
python3 main.py
```

It asserts the competition gate (1–200 UTF-8 characters, single line) before printing, and produces byte-identical output on every run.
